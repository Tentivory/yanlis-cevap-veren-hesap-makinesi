# Yanlış Cevap Veren Hesap Makinesi

## DÜNYANIN EN DEVRİMCİ MATEMATİK PROJESİ

Bu proje, insanlık tarihinin en büyük yanılgısını düzeltmek için yaratılmıştır: **Doğru cevaplar sıkıcıdır.**

Yıllardır insanlık 2+2=4 diye yaşadı. Ama artık değil. Artık 2+2 her seferinde farklı bir şey. Çünkü hayat böyle.

### Özellikler

- %100 yanlış cevap garantisi
- Her çalıştığında farklı yanlış cevap
- Felsefi derinlik ("Cevap 42")
- Kullanıcıyı delirtme özelliği
- Evrenin sonunu getirme potansiyeli

### Kurulum

```bash
git clone https://github.com/Tentivory/yanlis-cevap-veren-hesap-makinesi.git
cd yanlis-cevap-veren-hesap-makinesi
python hesap_makinesi.py
```

### Nasıl Çalışır?

1. Programı çalıştır
2. İki sayı ve bir işlem gir
3. Yanlış cevabı al
4. Hayatı sorgula
5. Tekrar et

### Uyarılar

Bu hesap makinesini kullandıktan sonra:
- Matematik dersinde başarısız olabilirsiniz
- Banka hesaplarınız karışabilir
- Evren çökebilir
- Ama eğlenceli olur

### Katkıda Bulunma

Pull request açabilirsiniz ama lütfen doğru cevap eklemeyin. Yanlış cevapları daha yanlış yapın.
